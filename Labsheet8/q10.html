• Uncompressed PNG & JPEG hero graphics (3.8 MB)
• Render-blocking unminified CSS & JS (850 KB)

Optimized Assets (Pipeline) 410 KB (-91.5%)

• Cumulative Layout Shift: 0.00 (Zero Shift)

3. Next-Gen Modern Image Pipeline

Demonstration of the HTML5 <picture> element serving responsive WebP variants with fallback and explicit layout dimensions.

<picture> <!-- Modern ultra-compact AVIF format for supporting browsers --> <source srcset="images/sourdough-400w.avif 400w, images/sourdough-800w.avif 800w" type="image/avif"> <!-- Compact WebP format for modern browsers --> <source srcset="images/sourdough-400w.webp 400w, images/sourdough-800w.webp 800w" type="image/webp"> <!-- Fallback JPEG with native lazy loading & fixed aspect-ratio preventing CLS --> <img src="images/sourdough-fallback.jpg" alt="Fresh wood-fired artisan sourdough loaf" width="800" height="500" loading="lazy" decoding="async"> </picture>
