Dynamic Root Variable Swapper

This web application demonstrates swapping CSS variables defined inside :root dynamically using JavaScript. When you toggle the switch above, JavaScript changes the active theme attribute and adjusts custom CSS properties such as --bg-body, --bg-card, --text-primary, and --accent-color in real time.

Semantic Tokens

Using centralized CSS variables avoids hardcoded hexadecimal colors across components.

Persistence

Your theme preference is automatically stored in localStorage so it survives page reloads.

Smooth Transition

All color and background transitions execute with 0.3s cubic timing for optimal visual ergonomics.

// JavaScript dynamic root CSS variable swap snippet:
document.documentElement.setAttribute('data-theme', 'dark');
// Or dynamically setting directly:
document.documentElement.style.setProperty('--bg-body', '#0b1120');
