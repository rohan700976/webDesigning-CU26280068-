Semantic HTML5 elements like <header>, <nav>, <main>, <section>, <article>, and <footer> clearly describe their meaning to both browsers and developers. They drastically boost Search Engine Optimization (SEO), improve accessibility for screen readers, and create clean, maintainable DOM trees.
CSS Flexbox is optimal for one-dimensional layouts (a single row or a single column), such as navigation bars, form controls, and linear card lists. CSS Grid is designed for two-dimensional layouts with rows and columns simultaneously, making it ideal for overall page scaffolding and complex galleries.
Each accordion heading has a click event listener attached. When triggered, JavaScript reads the content container's scrollHeight property and sets maxHeight smoothly in CSS, while toggling the .active class on the parent item to trigger chevron rotation.
The :root pseudo-class represents the highest-level element in the document tree. Declaring variables here (e.g. --primary: #2563eb) makes design tokens globally accessible, enabling instant theme switches (such as Light to Dark mode) by swapping variable values in one place.
